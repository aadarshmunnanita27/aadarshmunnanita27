### 👨‍💻 About Me

I'm a final-year CSE student at **NIT Agartala**, and I spend most of my time building things end-to-end — from database schema to the pixel on screen. I like backend work the most: designing APIs that don't fall over, thinking through edge cases before they bite in production, and understanding *why* a system is built the way it is, not just how to use it.

Right now I'm building **Neurixa-AI**, an AI-powered conversational assistant, where I'm getting hands-on with LLM tooling, prompt design, and the backend infrastructure needed to serve real-time AI responses reliably.

- 🔭 Currently working on **Neurixa-AI**
- 🌱 Deepening my knowledge of **System Design** and **scalable backend architecture**
- 💡 Interested in **LLM tooling**, **developer productivity tools**, and **clean API design**
- ⚡ Fun fact: my GitHub streak has outlasted more of my New Year resolutions than I'd like to admit
- 📫 Open to internships, collaborations, and interesting backend/full-stack problems
